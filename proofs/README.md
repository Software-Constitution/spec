# Proof pilot: Lean 4

Lean code in `proofs/Constitution.lean` proves **abstract** properties of levels and release prerequisites, including the impossibility of L2 without all six gates and release without authority/evidence.

The CI Lean job runs Lake against the pinned Lean toolchain. These proofs are **not a proof that scct.mjs implements the model**. Production-grade assurance next requires traceable model↔implementation refinement, negative tests, and independent provenance attestation. Do not claim Rust verification until an actual Aeneas translation and a compiled proof have passed.

Aeneas is a later opt-in verification adapter for suitable safe sequential Rust, not an assumed Rust-to-Lean replacement for the general-purpose specification.
