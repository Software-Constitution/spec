# Software Constitution — Standard Self-Governance

This repo is the **normative specification**. Its repository-scope constitution does not attest operation of the independently deployed website or other organizations.

## Mandatory rule classes

1. Zero Competing Systems
2. Zero Repo-Prod Drift
3. Zero Stubs
4. Self-Governance and Canonical-First
5. Zero-Deviation Mandate
6. Coherent Integration

Each rule is executed using constitution/gates.json. Site and downstream deploy attestations are separate scopes; no off-repo deployments may be asserted by this repository.

## Constitutional amendment

Changes require review of the full contract, six gates, negative conformance tests, and Lean model. CI evaluates an **L2 floor**, not higher certification.
